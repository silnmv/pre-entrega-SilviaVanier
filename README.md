"Merlina Sublimados"

Es un proyecto de página web, diseñada como parte del curso de Front-End. Este proyecto está estructurado en HTML, lenguaje standar para la creación de páginas webs.
En el archivo raíz "index.html", utilicé etiquetas semánticas para estructurar y organizar el contenido. 
Con CSS pude darle el estilo visual deseado. Priorizando obtener un diseño consistente, som repetir código y con un mismo criterio estético. 
Para lograr esto, utilicé CSS externo, guardando el CSS en un archivo aparte y vinculandolo con HTML usando link.

El formulario sirve para reunir datos de los posibles clientes e interesados en la empresa. Lo realice con "Fromspree", ya que permite enviar formularios sin la necesidad de configurar un servidor. 
En el archivo raiz se declara la URL a la que se envian los datos (action) y especifica el metodo de envio (method).

En el desarrollo utilicé la teoria de la cursada y me apoye buscando la sintaxis de lo que no recordaba. 
También en aquello que notaba no respondia de la forma que yo esperaba, le pedia a la IA que me ayude a encontrar el error, lo cual me fue de gran ayuda ya que en ocasiones era una mayuscula, la ausencia de un punto o un error de sintaxis. 

Por una cuestión estética, decidí no aplicar la imagen como banner ya que deseaba que cubriera el total del fondo.
